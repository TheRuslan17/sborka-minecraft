# 🎮 Minecraft Modpack Collection

Сборка модов для Minecraft 1.20.1 на Forge. Просто скачайте и играйте!

---

## 📋 Информация о сборке

| Параметр | Значение |
|----------|----------|
| **Версия Minecraft** | 1.20.1 |
| **Тип загрузчика** | Forge |
| **Версия Forge** | 47.4.10 |
| **Количество модов** | 96 |
| **Минимальная RAM** | 6 GB |
| **Рекомендуемая RAM** | 8+ GB |

## 🚀 Установка

### Способ 1: Через сайт (рекомендуется)
1. Перейдите на [сайт сборки](https://[ваш_логин].github.io/[репозиторий]/)
2. Нажмите кнопку **"Скачать сборку"**
3. Дождитесь загрузки ZIP-архива

### Способ 2: Вручную из репозитория
1. Скачайте файл `modpack.zip` из [релизов](https://github.com/[ваш_логин]/[репозиторий]/releases)
2. Или скачайте весь репозиторий

---

## 📦 Установка сборки

1. **Установите Forge 47.4.10** для Minecraft 1.20.1
   - Скачайте с [официального сайта](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)
   - Запустите установщик и выберите "Install client"

2. **Распакуйте архив**
   - Откройте папку с Minecraft (`.minecraft`)
   - Скопируйте все файлы из архива в папку `mods`
   - Если папки `mods` нет — создайте её

3. **Настройте RAM**
   - В лаунчере (TLauncher, MultiMC, Lunar Client и т.д.)
   - Выделите **минимум 6 GB**, лучше **8+ GB**

4. **Запустите игру**
   - Выберите профиль Forge 1.20.1
   - Наслаждайтесь игрой!

---

## 🔄 Обновление сборки

1. Скачайте новую версию с сайта
2. Удалите старые моды из папки `mods`
3. Распакуйте новый архив в папку `mods`
4. Запустите игру
